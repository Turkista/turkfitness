# assets/produtos/

Fotos de produto (peças de academia), sempre em `.webp`, proporção 3:4.

Este é o destino automático das fotos enviadas pelo **Painel Turk Fitness**
(aba Produtos) — o painel já converte pra `.webp` e salva aqui com o nome
certo. Você não precisa mexer nesta pasta manualmente.

Nomenclatura gerada pelo painel: `<slug-do-produto>.webp` (imagem de capa)
e `<slug-do-produto>-<cor>.webp` quando a peça tem mais de uma cor.
